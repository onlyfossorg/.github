**ONLY FOSS ORG** is an independent Free and Open Source Software community.

We exist to fix one core problem in college tech culture:

> **Good projects shouldn’t die after a semester.**

---

## 🌱 Why ONLY FOSS ORG?

Every semester, students build projects.
Some are average.
Some are **really good**.
A few can grow into real products.

But most of them get abandoned.

ONLY FOSS ORG is here to change that by:
- Keeping old college projects alive as open source
- Encouraging open-source collaboration
- Running small competitions and hackathons so students stay engaged
- Helping people find teammates, contributors, and mentors
- Building real-world engineering habits

---

## 🧩 What We Do

- Maintain a **public directory of college projects kept alive as open source**
- Enable contributions via **GitHub pull requests**
- Encourage collaboration across years, campuses, and departments
- Help solo developers find teams for hackathons and competitions
- Promote clean code, documentation, and ownership

This is not a club for certificates.  
This is a space for **builders**.

---

## 📂 Project Directory

All community projects live in our central registry:

👉 **[`awesome-foss`](https://github.com/onlyfossorg/awesome-foss)**

Each project:
- Has a clear roadmap
- Lists maintainers and contact points
- Is open for contributions (unless marked otherwise)

Projects are showcased on our website:
👉 **https://onlyfossorg.github.io**

---

## 🤝 Who Can Join?

Builders, indie hackers, and beginners are all welcome.

Anyone who:
- Likes building things
- Wants to contribute to real projects
- Is curious about open source
- Wants to learn by doing

You don’t need to be an expert.
You just need to start.
